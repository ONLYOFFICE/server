Start

Add to autostart

sudo systemctl enable ds-example

Start

net start DsExampleSvc

Add to autostart

sc.exe config DsExampleSvc start= auto

Start

sudo docker exec $(sudo docker ps -q) sudo supervisorctl start ds:example

Add to autostart

sudo docker exec $(sudo docker ps -q) sudo sed 's,autostart=false,autostart=true,' -i /etc/supervisor/conf.d/ds-example.conf

For information on how to launch the test example, see the Kubernetes deployment notes.

Stop

sudo systemctl stop ds-example

Remove from autostart

sudo systemctl disable ds-example

Stop

net stop DsExampleSvc

Stop

sudo docker exec $(sudo docker ps -q) sudo supervisorctl stop ds:example

Remove from autostart

sudo docker exec $(sudo docker ps -q) sudo sed 's,autostart=true,autostart=false,' -i /etc/supervisor/conf.d/ds-example.conf

Disable the test example in the Helm release

helm upgrade documentserver onlyoffice/docs --set example.enabled=false --no-hooks

documentserver is the release name from the official Kubernetes example; replace it with your own release name if different.

Note Use this only for testing purposes. Disable it before putting your server into production.
