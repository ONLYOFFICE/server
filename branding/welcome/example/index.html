Start

sudo systemctl enable ds-example

Start

net start DsExampleSvc

Add to autostart

sc.exe config DsExampleSvc start= auto

Start

sudo docker exec $(sudo docker ps -q) sudo supervisorctl start ds:example

Add to autostart

sudo docker exec $(sudo docker ps -q) sudo sed 's,autostart=false,autostart=true,' -i /etc/supervisor/conf.d/ds-example.conf

Enable the test example in the Helm release

helm upgrade documentserver onlyoffice/docs --set example.enabled=true --no-hooks

documentserver is the release name from the official Kubernetes example; replace it with your own release name if different.

Note Use this only for testing purposes. Disable it before putting your server into production.

Admin Panel

Start

sudo systemctl start ds-adminpanel

Add to autostart

sudo systemctl enable ds-adminpanel

Start

net start DsAdminPanelSvc

Add to autostart

sc.exe config DsAdminPanelSvc start= auto

Start

sudo docker exec $(sudo docker ps -q) sudo supervisorctl start ds:adminpanel

Add to autostart

sudo docker exec $(sudo docker ps -q) sudo sed 's,autostart=false,autostart=true,' -i /etc/supervisor/conf.d/ds-adminpanel.conf

Enable the Admin Panel in the Helm release

helm upgrade documentserver onlyoffice/docs --set adminpanel.enabled=true --no-hooks

documentserver is the release name from the official Kubernetes example; replace it with your own release name if different.

Important The Admin Panel has no administrator account yet. The first administrator can only be created from the host — run documentserver-admin create-admin, then reload. See the Admin Panel guide.
